プライバシーポリシー

最終更新日：2026年11月8日

要点（詳細は各セクションをご確認ください） ディクテーションで入力したテキストは端末内で処理します。ただし、AI分析（Pro・トライアル）を実行した場合に限り、間違えた単語と該当する英文をAI分析のために送信します。聞き取りの苦手な音の記録（苦手マップ）は端末内だけに保存します。サーバーに送る学習統計は、音の種類ごとの回数など個人を特定できない数値だけで、入力したテキストや英文は含みません。収集データは学習進捗の管理、AI分析、広告配信（無料ユーザーのみ）、およびアプリ改善のための匿名統計分析に限定しています。

1. はじめに

本プライバシーポリシーは、DictaFlow（以下「本アプリ」）における個人情報の取り扱いを説明します。本アプリは、YouTube動画を使った英語ディクテーション学習を提供するiOSアプリです。

本アプリをご利用になることで、本ポリシーに同意したものとみなします。

開発者： DictaFlow開発チーム
連絡先： dictaflow.app@gmail.com

2. 収集する情報

2-1. 自動的に収集される情報

データ種別 収集方法 目的
匿名ユーザーID CloudKit / Apple認証 アカウント管理・デバイス間同期
学習記録
（動画・スコア・streak）		 アプリ内操作 進捗表示・iCloudバックアップ
アプリ操作ログ Firebase Analytics 機能改善・クラッシュ検知
匿名の学習統計
（バージョン1.4以降）		 学習セッションの終了時に自動送信（Amazon Web Services） 英語学習者が聞き取りにくい音の傾向を分析し、教材と機能を改善するため。
送信するのは、音の特徴（弱く読む語、音のつながりなど）ごとの出現回数と聞き落とした回数、取り違えの種類ごとの回数、学習したYouTube動画のID、アプリのバージョン、アプリ内で生成した端末ID（サーバー側でハッシュ化して保存）だけです。入力したテキスト、英文、単語は含みません。

2-2. ユーザーが任意に提供する情報

データ種別 取り扱い
ディクテーション入力テキスト 端末内で処理します。AI分析を実行した場合のみ、下記「AI分析リクエスト」の範囲で送信します。
AI分析リクエスト AI分析を実行したときに、間違えた単語（正解とあなたの入力）、該当する英文、端末で判定した音の特徴（英文側の語と、聞き取れたかどうか。バージョン1.4以降）、表示言語、アプリ内で生成した端末ID（サーバー側でハッシュ化して保存）を送信します。
送信先：バージョン1.3以降は Amazon Web Services（Amazon Bedrock 上の Anthropic 社 Claude モデル。日本国内のリージョンで処理）、バージョン1.2以前は Google（Firebase AI Logic 経由の Gemini）。
Amazon Bedrock では、送信内容はモデルの学習に使用されず、モデル提供元（Anthropic 社）にも共有されません。分析の入出力は、品質改善と不具合調査のため最大90日間保存し、その後自動で削除します。
追加したYouTube動画URL 端末内に保存。動画メタデータ取得のためYouTube Data APIに送信。

3. 情報の利用目的

  • 学習進捗の管理・表示（streak、スコア履歴、弱点分析）
  • 聞き取りの苦手な音の分析（苦手マップ。端末内で処理）
  • 複数デバイス間での学習データの同期（iCloud経由）
  • サブスクリプション管理（StoreKit 2 / App Store）
  • 広告配信（無料プランユーザーのみ）
  • アプリの品質向上・クラッシュ修正
  • 匿名の学習統計にもとづく教材・機能の改善

4. 第三者への情報提供

以下の目的のため、必要最小限の情報を第三者サービスに提供しています。

目的 提供する情報
iCloud同期（Apple） 学習データ（匿名ID紐付け）
アクセス解析・クラッシュ検知 操作ログ・デバイス情報
広告配信（無料ユーザーのみ） 広告識別子・デバイス情報
動画メタデータ取得（YouTube） 動画URL
AI分析（Amazon Web Services / Google） 間違えた単語・該当する英文・音の特徴の判定結果・表示言語・アプリ内で生成した端末ID（AI分析を実行した場合のみ）
学習統計の保存（Amazon Web Services） 匿名の学習統計（音の特徴ごとの回数・YouTube動画のID・アプリのバージョン・ハッシュ化した端末ID）

上記以外の目的で個人情報を第三者に販売・提供することはありません。

5. YouTubeコンテンツについて

本アプリはYouTube動画を学習素材として利用します。動画コンテンツはYouTubeが提供するものであり、YouTubeのプライバシーポリシー（policies.google.com/privacy）が適用されます。

取得した字幕データは学習目的のみに使用し、端末内に一時的にキャッシュします（最大30日）。

6. データの保存と削除

保存場所

  • 学習データ：端末内（SwiftData）および iCloud（CloudKit）
  • 苦手マップの記録：端末内のみ（送信しません）
  • 匿名ログ：Firebase（最大14ヶ月）
  • 匿名の学習統計：AWS（最大2年。その後自動で削除）
  • AI分析の入出力：AWS（最大90日）

データ削除

アプリを削除すると端末内のデータはすべて消去されます。iCloudに同期されたデータは、iCloud設定よりアプリデータを削除することで消去できます。サーバー側の匿名データの削除をご希望の場合は、dictaflow.app@gmail.com までお問い合わせください。

7. 広告とトラッキング（App Tracking Transparency）

無料プランでは広告を表示します。本アプリはAppleのApp Tracking Transparency（ATT）フレームワークに準拠しており、広告トラッキングの前に許可を求めます。許可しない場合、パーソナライズされていない広告が表示されます。

Proプランではすべての広告が非表示になります。

8. 年齢制限

本アプリは13歳未満の方の利用を対象としていません。13歳未満の方が個人情報を提供していると判明した場合、速やかに削除します。

9. プライバシーポリシーの変更

本ポリシーは変更される場合があります。重要な変更がある場合は、アプリ内通知またはこのページでお知らせします。変更後も本アプリをご利用の場合は、新しいポリシーに同意したものとみなします。
